# Deployment Checklist — German Credit Risk Endpoint

## Pre-Deployment Controls
- [ ] Model artifact generated from version-controlled training script
- [ ] Metrics reviewed and recorded in `training/metrics.json`
- [ ] Model card completed
- [ ] Data sheet completed
- [ ] Target mapping documented
- [ ] Deployment config reviewed
- [ ] Scoring script includes traceable response fields
- [ ] Rollback plan documented
- [ ] Known limitations explicitly stated
- [ ] Non-production educational use confirmed

## Deployment Approval Gate
- [ ] Technical review completed
- [ ] Governance documentation complete
- [ ] Release note prepared
- [ ] Endpoint naming reviewed
- [ ] Access mode reviewed

## Post-Deployment Controls
- [ ] Smoke test completed
- [ ] Sample response verified
- [ ] Prediction logging approach defined
- [ ] Monitoring plan documented
